# FontMod — 도구 소스 전용

[English](README.md) · [简体中文](README.zh-Hans.md) · [繁體中文](README.zh-Hant.md) · [Español](README.es.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

이 저장소에는 도구와 라이선스 고지만 포함되며 글꼴과 이미지는 포함되지 않습니다. [TOOL-INPUTS.md](TOOL-INPUTS.md)의 경로와 해시에 맞는 사용 권한이 있는 입력을 준비하세요.

`./fontmod source-check`, `./fontmod setup`, `./fontmod build --departure-build /path/to/build`를 실행하세요. setup에는 네트워크가 필요합니다. 입력이 없거나 해시가 다르면 빌드가 실패합니다. Nerd 글리프는 유지됩니다. 제3자 그림과 상표 권리는 미확인이며 이 도구의 공개는 생성된 글꼴의 공개를 허가하지 않습니다. [라이선스](LICENSE-SCOPE.md) · [영문 안내](RELEASE.en.md).

선택 사항인 RysaMix 및 Glyphgrove 도구는 외부 입력을 사용합니다. [TOOL-INPUTS.md](TOOL-INPUTS.md)를 참고하세요. 글꼴과 파생물의 라이선스는 도구와 별개입니다.
